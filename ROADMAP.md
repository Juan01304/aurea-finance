# Roadmap

## Escopo de portfólio concluído

- [x] landing page responsiva;
- [x] cadastro com confirmação por OTP;
- [x] login em duas etapas;
- [x] recuperação de senha;
- [x] onboarding e perfil financeiro;
- [x] contas recorrentes e status mensal;
- [x] transações, renda extra e categorias;
- [x] metas financeiras e contribuições;
- [x] limites por categoria;
- [x] Saúde do Orçamento, reserva adaptativa e teto seguro diário/mensal;
- [x] histórico resumido de seis meses;
- [x] assistente local e OpenAI opcional com fallback;
- [x] exportação CSV/JSON;
- [x] tema claro/escuro e PWA;
- [x] SQLite e PostgreSQL;
- [x] Docker + Render Blueprint;
- [x] testes unitários, smoke test e fluxo PostgreSQL no GitHub Actions;
- [x] política de privacidade, termos, documentação de segurança e arquitetura.

## Próximo nível, fora do escopo do MVP

- frontend separado e API versionada;
- migrações de banco versionadas;
- filas de e-mail;
- observabilidade e tracing;
- testes E2E em navegador;
- rate limiting distribuído;
- backups automatizados e disaster recovery;
- domínio próprio e fluxo jurídico/LGPD de produção;
- revisão externa de segurança e acessibilidade.
