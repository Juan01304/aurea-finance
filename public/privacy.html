AAurea Finance

Privacidade

Última atualização: 20 de agosto de 2026.

Dados tratados

A Aurea armazena os dados necessários para a conta e para o planejamento financeiro informado pelo próprio usuário, como e-mail, nome, renda, contas, transações, metas e limites.

Segurança

Senhas são armazenadas com hash PBKDF2-HMAC-SHA256. Códigos OTP são armazenados como HMAC, sessões ficam no servidor e operações autenticadas de escrita usam token CSRF.

IA

Quando a IA em nuvem está habilitada, um contexto financeiro limitado pode ser enviado à API da OpenAI para responder à pergunta. A chave da API permanece no servidor. O usuário pode desabilitar esse modo nas configurações.

Controle do usuário

O usuário pode exportar seus dados em JSON/CSV e excluir a conta pelo painel. A exclusão remove os registros vinculados à conta no banco da aplicação.

Demonstração

Usuários de demonstração são temporários e são removidos automaticamente após o período definido pelo serviço.

Escopo

Este é um projeto educacional/portfólio. Uma operação comercial exigiria documentação jurídica, governança e procedimentos LGPD adicionais.
